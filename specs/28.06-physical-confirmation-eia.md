## 3. Derived weekly row → `grp.physical_weekly`

For the latest `week_ending`:
- `gulf_imports_kbd`, `total_imports_kbd`, `spr_mb`, `utilisation_pct` from the series.
- `spr_change_mb = spr_mb − previous week` (negative = draw).
- `utilisation_chg = utilisation_pct − previous week` (points).
- `imports_z_13w = (gulf_imports_kbd − mean(prev 13 weeks)) / std(prev 13 weeks)`, std floor 25 kb/d.
- `source_series` = `{series_id: value}` for audit.

Upsert on `week_ending`. Also back-fill the last 60 weeks on first run so z-scores are valid immediately.

## 4. Scoring input (`eia_term`, consumed by 28.08 §5)

```
imports_part = clip(−imports_z_13w / imports_z_divisor(2.0), 0, 1)     # Gulf imports collapsing = confirmation
spr_part     = spr_draw_add(0.30) if spr_change_mb < −spr_draw_flag_mb(2.0) else 0
util_part    = util_drop_add(0.20) if utilisation_chg < −util_drop_flag_pts(1.5) else 0
eia_term     = clip(imports_part + spr_part + util_part, 0, 1)
```

Rationale: Gulf-origin barrels failing to arrive on US shores is the cleanest weekly print of a Hormuz disruption; an SPR draw is the policy response confirming it; a utilisation drop says refiners lost feedstock. These lag the tape by 2–4 weeks — that is the point: they confirm or refute what the news and AIS layers claimed.

`eia_term` is held constant between Wednesdays. It is `stale` if the latest `week_ending` is more than 12 days old (WPSR delays around holidays are tolerated).

---

## 5. Combining with AIS (`physical`, 28.08 §5)

`physical = ais_weight(0.60) × ais_term + eia_weight(0.40) × eia_term`. `ais_term` from 28.05 daily aggregates (28.08 §5 defines the z-score construction). When AIS history < 30 days, `ais_term` is down-weighted by `days_available / 30` and the remainder of the weight shifts to `eia_term`.
