Railway and Grafana cloud are **not** set up. Everything through Phase 3 runs locally on docker-compose. Phase 4 maps the same services onto Railway once the phase-one infra spec (`claude-code-instructions-detailed.md`) has been executed.

## 2. `docker-compose.yml`

If the repo has none yet, create it; if it exists, **add** the `grp-*` services and switch the Postgres image to `pgvector/pgvector:pg16` (drop-in compatible).

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg16
    environment: { POSTGRES_USER: energy, POSTGRES_PASSWORD: energy, POSTGRES_DB: energy }
    ports: ["5432:5432"]
    volumes: ["pgdata:/var/lib/postgresql/data"]
    healthcheck: { test: ["CMD-SHELL","pg_isready -U energy"], interval: 5s, retries: 10 }

  api:
    build: { context: ., dockerfile: api/Dockerfile }
    env_file: .env
    environment: { DATABASE_URL: "postgresql+psycopg://energy:energy@postgres:5432/energy", GRP_ALLOW_RUN: "1" }
    ports: ["8000:8000"]
    volumes: ["./exhibits:/app/exhibits"]
    depends_on: { postgres: { condition: service_healthy } }

  grafana:
    image: grafana/grafana-oss:11.2.0
    ports: ["3000:3000"]
    environment:
      GF_SECURITY_ADMIN_PASSWORD: admin
      GF_INSTALL_PLUGINS: ""
    volumes:
      - ./grafana/provisioning:/etc/grafana/provisioning
      - ./grafana/dashboards:/var/lib/grafana/dashboards
      - ./grafana/static:/usr/share/grafana/public/grp_static
      - grafana-data:/var/lib/grafana
    depends_on: [postgres]

  grp-ais:
    build: { context: ., dockerfile: grp/Dockerfile }
    command: python -m grp.jobs.job_ais
    env_file: .env
    environment: { DATABASE_URL: "postgresql+psycopg://energy:energy@postgres:5432/energy" }
    restart: unless-stopped
    depends_on: { postgres: { condition: service_healthy } }

  grp-scheduler:
    build: { context: ., dockerfile: grp/Dockerfile }
    command: python -m grp.jobs.scheduler        # APScheduler loop running the cron table below; local stand-in for Railway cron
    env_file: .env
    environment: { DATABASE_URL: "postgresql+psycopg://energy:energy@postgres:5432/energy" }
    volumes: ["./exhibits:/app/exhibits"]
    restart: unless-stopped
    depends_on: { postgres: { condition: service_healthy } }

volumes: { pgdata: {}, grafana-data: {} }
```

`grafana/provisioning/datasources/postgres.yaml` points at `postgres:5432` with the compose credentials (env-substituted). `grp/Dockerfile`: python 3.11-slim, install deps, pre-download the MiniLM model into the image layer (`python -c "from sentence_transformers import SentenceTransformer as S; S('sentence-transformers/all-MiniLM-L6-v2')"`), copy `grp/`, `db/`.

`grp/jobs/scheduler.py`: APScheduler `BlockingScheduler` reading the cron table (§5) — **local only**; on Railway each job becomes a cron service and this file is unused.

## 3. `Makefile` targets

```
make up            # docker compose up -d --build
make down
make migrate       # psql -f grp/store/migrations/0001_grp_schema.sql (or alembic upgrade head)
make test          # pytest grp/tests api/tests -q
make run JOB=news  # docker compose exec api python -m grp.jobs.job_$(JOB)

```

## 8. Definition of done (v1, local)

- `make up migrate test` green from a fresh clone with `.env` filled.
- `GET /grp/latest` returns a non-null composite with all components; `stale=[]` in normal operation and degrades correctly with any single feed down.
- Grafana "GRP — Gulf" shows the header + 10 panels over live data at `localhost:3000`.
- A pasted X post lands in the score within one composite cycle (≤ 30 min).
- Exhibits and event card generated for a real event and consumable by the writing agent without edits.
- No secrets in the repo; `ARCHITECTURE.md`, `README.md`, `DEPLOY.md` current.
