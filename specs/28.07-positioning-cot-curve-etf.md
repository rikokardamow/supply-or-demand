# Spec 28.07 — Positioning: COT, Curve, ETF Flows, Crowded Flag

Job: `grp/jobs/job_positioning.py` — daily 22:00 UTC. COT updates Fridays 20:30 UTC (data as of Tuesday). Produces one `grp.positioning` row per calendar day; non-COT days carry the last COT values forward with fresh curve/ETF values.

---

## 1. CFTC Commitments of Traders — `ingest/cot_cftc.py`

### 1.1 Current week
`GET https://www.cftc.gov/dea/newcot/f_disagg.txt` — Disaggregated Futures-Only, CSV with header row. Columns of interest (names as in the file header; match case-insensitively and tolerate quoting):

- `Market_and_Exchange_Names`, `As_of_Date_In_Form_YYMMDD` / `Report_Date_as_YYYY-MM-DD`, `CFTC_Contract_Market_Code`
- `M_Money_Positions_Long_All`, `M_Money_Positions_Short_All`, `M_Money_Positions_Spread_All`
- `Open_Interest_All`

Filter rows where `CFTC_Contract_Market_Code` ∈ `{067651 (WTI, NYMEX), 06765T (Brent Last Day, ICE — verify code in file), 111659 (RBOB), 022651 (HO)}`. Net = `Long − Short`.

### 1.2 History back-fill (first run only)
`GET https://www.cftc.gov/files/dea/history/fut_disagg_txt_{year}.zip` for the last 3 years → same columns → build the 2-year window for percentiles. Store every report date in a helper table `grp.cot_history (report_date date, market text, mm_long bigint, mm_short bigint, mm_net bigint, oi bigint, primary key (report_date, market))` — add to 28.02.

### 1.3 Percentile
`wti_net_pct_2y` = percentile rank of the latest `wti_mm_net` within the trailing `lookback_days` (730) of `cot_history`. Same for Brent. If Brent code absent from the file, `brent_*` null and the crowded rule uses WTI only.

---

## 2. Curve — `ingest/curve_markets.py`

Reads the repo's `markets` schema (own settles scraper). Required: Brent futures settles for M1, M3, M12 (front three consecutive months and the twelfth) by settlement date, and front-month implied vol if the scraper stores it (else null — **do not** scrape exchange JS endpoints).

- `brent_m1_m3 = M1 − M3` (positive = backwardation), `brent_m1_m12 = M1 − M12`.
- `brent_m1_m3_chg_5d = brent_m1_m3(t) − brent_m1_m3(t−5 sessions)`.

If the `markets` schema doesn't yet carry Brent M3/M12, add the contracts to that scraper's list (second permitted external edit; document it) — or, if no settles scraper exists at all, set curve fields null and let the crowded rule degrade (§4).

---

## 3. ETF flows — `ingest/etf_flows.py`

Daily shares outstanding and NAV for USO (USCF), BNO (USCF), XLE (SSGA). Scrape the issuer holdings/summary pages with `httpx` + BeautifulSoup; selectors in `sources.yaml` under `etf_flows.pages` (add when implementing, after inspecting the pages). `flow_usd = Δshares_outstanding × NAV`. Tolerate any failure: null the value, log, do not fail the job. This is the weakest input and only a tie-breaker — treat accordingly.

---

## 4. Crowded flag — `compute/positioning.py`

```
pct      = max(wti_net_pct_2y, brent_net_pct_2y or 0)
widening = brent_m1_m3_chg_5d > 0 if available else False
phys     = latest physical component from grp.components (28.08), default 0.5 if none yet

crowded  = pct >= 0.80 and phys < 0.40 and (widening or curve unavailable)
crowded_reason = f"mm_net_pct={pct:.2f} physical={phys:.2f} m1m3_5d={chg}"
```

Interpretation: managed money is long at a 2-year extreme, the front of the curve is being bid harder, and the barrels are not confirming → the premium is positioning-driven and fade-prone. `crowded` feeds the composite penalty and the `fade` flag (28.08 §6).

## 5. Output row

Upsert `grp.positioning` for `d = today (UTC)` with all fields; `cot_report_date` = latest report date used.

Grafana panel 9 (28.10) plots `wti_net_pct_2y`/`brent_net_pct_2y` against `brent_m1_m3` on a dual axis.
