# Spec 28.08 — TACO Credibility, Escalation, Component Scores, Composite

Job: `grp/jobs/job_composite.py` — every 30 minutes, and invoked in-process by `job_news` after any severity ≥ 4 event, by `job_notam` after any severity ≥ 3 NOTAM, and by `job_ais` after a cluster event. Idempotent: writes `(ts, theatre)` rows keyed on the run timestamp truncated to the minute.

Order inside a run: `baselines → taco → escalation → airspace → physical → positioning(read) → composite → alerts`.

---

Shared helpers, all pure functions:

## 2. TACO — `compute/taco.py`

### 2.1 Pairing (event-driven + sweep)

`on_new_event(ev)` (called by 28.03 §7.5 and by feed event inserts):
- If `ev.type == 'threat'`: nothing yet (row is open; `resolution is null`).
- If `ev.type ∈ {strike, seizure, sanction}`: find the **oldest open threat** by `ev.actor` with `first_seen ∈ [ev.first_seen − 72 h, ev.first_seen]`. If found → `resolve_threat(threat.id, 'follow_through', child_id=ev.id, at=ev.first_seen)` and set `ev.parent_threat_id`. (`references_prior_threat` from the classifier extends the search window to 168 h.)
- If `ev.type ∈ {walk_back, denial, talks}`: same lookup → `resolve_threat(..., 'walk_back', ...)`. Only the **actor's own** walk-back resolves the actor's threat; the counterparty accepting talks does not.

`sweep()` (each composite run): open threats older than `window_hours` (72) → `resolve_threat(id, 'walk_back', None, at = first_seen + 72 h)` if `silence_counts_as_walk_back` (true).

A threat resolves once; later strikes create new events with no parent.

### 2.2 Credibility

Per `(theatre, actor)`, over threats with `first_seen ≥ today − rolling_days` (90):

```
ft   = count(resolution == 'follow_through')
wb   = count(resolution == 'walk_back')
open = count(resolution is null)
credibility = (ft + prior_weight × prior_credibility) / (ft + wb + prior_weight)
            = (ft + 3 × 0.5) / (ft + wb + 3)
```

Write `grp.taco` for `d = today`. Actors with zero threats get `credibility = prior (0.5)`.

**Dominant actor** for the composite = actor with the largest `escalation_mass` (§3) over the last 48 h among `count_types` events. `taco_dominant` = that actor's credibility. If dominant is `OTHER`, use the theatre-wide credibility (all actors pooled).

## 3. Escalation — `compute/escalation.py`

Over events with `type ∈ count_types` and `first_seen ≥ now − lookback_days` (7):

```
mass_i = severity_scale[severity] × tier_weight[source_tier] × decay(age_h, half_life_hours=36) × min(1, 0.5 + 0.1 × item_count)
mass   = Σ mass_i
escalation = 1 − exp(−mass / squash_divisor)          # divisor 2.0, config
```

The `item_count` factor rewards corroboration (1 item → 0.6, 5+ items → 1.0). `walk_back/denial/talks/other` contribute no mass.

Also compute `escalation_48h_ago` (same formula evaluated at `now − 48 h` using events that existed then, i.e. `first_seen ≤ now − 48 h`) for the fade test.

**Calibration note for `README.md`:** on first live run, print `mass` and `escalation` for the 5 Sep 2026 Kharg-strike tape; target ≈ 0.6–0.7 with the strike (sev 4, tier 2, ~10 items) plus the C-32A landing (sev 4, tier 1) and surrounding threats. Adjust `squash_divisor` in config, bump `model_version`, record the reasoning.

## 4. Airspace — `compute/airspace.py`

Inputs from 28.04 §4: `notam_term`, `aircraft_term`, `delay_term`.

```
airspace = notam_weight(0.50) × notam_term + aircraft_weight(0.30) × aircraft_term + delay_weight(0.20) × delay_term
```

Store the three terms in `grp.components` for the stacked panel.

## 5. Physical — `compute/physical.py`

**`ais_term`** from `grp.ais_daily` (yesterday's row per geofence vs 30-day baseline):

```
per geofence g:
  off_z    = z(ais_off_count)         # positive = more blackouts
  uturn_z  = z(uturn_count)
  count_z  = −z(tanker_count)         # fewer tankers at Kharg/Hormuz = disruption
  g_term   = clip01(max(off_z, uturn_z, count_z) / z_divisor(3.0))
ais_term = weighted mean over geofences, weights {kharg_anchorage: 0.35, hormuz_tss: 0.35, bab_el_mandeb: 0.15, fujairah: 0.10, suez_south: 0.05}
ais_term *= min(1, days_available / 30)
```

**`eia_term`** from 28.06 §4.

```
physical = ais_weight(0.60) × ais_term + eia_weight(0.40) × eia_term
(if ais history < 30 d: physical = w_ais' × ais_term + (1 − w_ais') × eia_term with w_ais' = 0.60 × days/30)
```

## 6. Composite — `compute/composite.py`

```
crowded = latest grp.positioning.crowded (today or most recent; default false if none)

grp_raw = w_e × escalation × taco_dominant + w_a × airspace + w_p × physical     # ∈ [0, 1]
grp     = 100 × grp_raw × (1 − crowded_penalty × crowded)

regime  = 'calm' if grp < 25 else 'elevated' if grp < 50 else 'stressed' if grp < 75 else 'crisis'

fade    = (escalation_48h_ago − escalation ≥ 0.15) and (taco_dominant < 0.40) and (crowded or not requires_crowded)
```

### 6.1 Staleness
For each feed in `sources.yaml` with a cadence: `age_min = now − feed_status.last_success`; stale if `age_min > staleness_multiplier × cadence_min` **or** `last_success is null`. Component handling when a feed is stale:
- The component that depends on it **keeps its previous stored value** (last row of `grp.components`), never zero.
- `scores.stale` lists the feed names.
- If **all** feeds behind a component are stale for > 24 h, that component is marked in `stale` as `component:<name>` and still carried forward — the composite continues, the dashboard shows amber.

### 6.2 Writes
`insert_components(ts, theatre, escalation, escalation_mass, dominant_actor, taco_dominant, airspace, notam_term, aircraft_term, delay_term, physical, ais_term, eia_term, crowded)` then `insert_score(ts, theatre, grp, regime, fade, model_version, stale)`.

### 6.3 Alert hooks
Load `prev = latest score before ts`. Call `alerts.engine.on_score(score, prev)` (28.10 §5): fires `regime_change`, `fade_trigger`. Then `alerts.engine.on_feeds(feed_health())` for `feed_stale`.

## 7. Worked example (for `tests/test_composite.py`)

5 Sep 2026 tape, 14:30 UTC, hypothetical inputs:
- Events: tanker strike sev 4 tier 2 (10 items, 1 h old) mass = 0.75×0.7×0.98×1.0 = 0.515; C-32A landing sev 4 tier 1 (3.5 h old) = 0.75×1.0×0.935×0.8 = 0.561; Iranian threat sev 3 tier 1 (20 h old) = 0.5×1.0×0.68×0.7 = 0.238; total 1.314 → escalation = 1 − e^(−0.657) = 0.482.
- Dominant actor US (mass 1.076); US threats in 90 d: 4, follow-throughs 1, walk-backs 3 → taco = (1+1.5)/(4+3) = 0.357.
- Airspace: one sev-4 NOTAM (0.8), landing 0.5×2^(−3.5/24)=0.45, delays 0 → 0.5×0.8 + 0.3×0.45 = 0.535.
- Physical: ais_term 0.30 (14 days history → ×0.47 = 0.14), eia_term 0.20 → w_ais' = 0.28 → 0.28×0.30 + 0.72×0.20 = 0.228.
- crowded = true (WTI net p85, physical 0.23, M1–M3 widening).
- grp_raw = 0.40×0.482×0.357 + 0.25×0.535 + 0.35×0.228 = 0.0688 + 0.1338 + 0.0798 = 0.282 → grp = 28.2 × 0.7 = **19.8 → calm**.
- fade: escalation 48 h ago 0.20 → drop −0.28 (rising, not falling) → false.

The test pins these numbers (tolerance 1e-3). The example also shows the design intent: a low-credibility actor's dramatic tape does not on its own push the score into `stressed` — barrels and airspace have to confirm it.
