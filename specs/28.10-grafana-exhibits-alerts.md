Dashboard uid `grp-gulf`, title "GRP — Gulf", refresh `5m`, default range `now-14d`, dark theme. Variables: `theatre` (query `select distinct theatre from grp.scores`, default `gulf`).

### 2.6 `jobs/job_exhibits.py`
Triggers: daily 06:00 UTC (`trigger=daily`), and in-process from the alert engine on `regime_change`, `fade_trigger`, `severity_5`. Writes to `$GRP_EXHIBIT_DIR/` with names `YYYY-MM-DD_<event_id or 'daily'>_<kind>.{png,svg,json}`, inserts `grp.exhibits` rows. Idempotent per `(date, trigger, event_id)`.

## 4. Sinks — `grp/alerts/sinks.py`

- `LogSink`: structured log line `{"alert": rule_id, ...payload}`.
- `EmailSink`: SMTP (`ALERT_SMTP_*`, STARTTLS), subject `[GRP {regime}] {rule_id}: {short}`, plain-text body with the event/score summary and the API link; attaches PNGs listed in `payload.exhibits` if under 2 MB total. If SMTP env missing → sink disabled with one warning at startup, not per alert.
- `ExhibitSink`: calls `job_exhibits.run(trigger=rule_id, event_id=…)` synchronously and adds the paths to the payload before `EmailSink` runs (order sinks: log → exhibit → email).
- `TelegramSink`: stub raising `NotImplementedError`; config flag `alerts.telegram.enabled=false` (P1).
