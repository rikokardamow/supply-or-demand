# Spec 28.03 — News Ingestion, De-duplication, Classification

Job: `grp/jobs/job_news.py` — every 15 minutes. Pipeline per run:

```
fetch (newsapi, worldnews, gdelt) → normalise → upsert grp.raw_items
→ embed new items → dedup (attach to existing event or mark candidate)
→ classify candidates (Haiku; Sonnet judge on low confidence) → insert grp.events
→ taco pairing hook (28.08) → alert engine hook (28.10) → feed_status
```

The manual/X path (`POST /grp/events`, 28.09) runs the same `normalise → upsert → embed → dedup → classify` sequence synchronously and returns the resulting event.

---

## 1. `ingest/base.py` — contract every feed implements

```python
class BaseFeed(ABC):
    name: str                       # key in sources.yaml and grp.feed_status
    def __init__(self, cfg: GrpConfig, http: httpx.Client, repo: Repo): ...
    def required_env(self) -> list[str]
    def fetch(self, since: datetime) -> list[dict]          # raw provider payloads
    def normalise(self, raw: list[dict]) -> list[RawItem]   # Pydantic
    def run(self, since: datetime | None = None) -> int:
        # missing env → repo.feed_error(name, "missing env ...") and return 0 (no raise)
        # try: rows = normalise(fetch(since)); n = repo.upsert_raw_items(rows); repo.feed_ok(name, n); return n
        # except: repo.feed_error(name, str(exc)); raise
```

Retry policy for all HTTP: 3 attempts, exponential backoff 1 s / 4 s / 9 s with ±30 % jitter, retry only on 429/5xx/timeouts. `since` defaults to `feed_status.last_success − 5 min`, floor `now − 24 h` on first run.

`RawItem` (Pydantic): `source, source_id, published_at, title, body, url, outlet, lang, author, raw`.

`source_id`: provider id when given; otherwise `sha1(url)`; for `x_paste`, `sha1(author + text[:200] + published_at.isoformat())`.

## 2. NewsAPI — `ingest/news_newsapi.py`

**Request:** `GET https://newsapi.org/v2/everything`
Headers: `X-Api-Key: $NEWSAPI_KEY`
Params:
- `q` = built from theatre config: `(Kharg OR "Strait of Hormuz" OR Hormuz OR Fujairah OR "Bab el-Mandeb" OR "Red Sea" OR "Persian Gulf") AND (Iran OR IRGC OR tanker OR strike OR Houthi OR Israel OR CENTCOM)` — max 500 chars, URL-encoded, quote multi-word terms.
- `from` = `since` ISO-8601, `sortBy=publishedAt`, `language=en`, `pageSize=100`, `page=1..N` while `totalResults > page×100` and `page ≤ 5`.

**Response:** `{status, totalResults, articles:[{source:{id,name}, author, title, description, content, url, publishedAt}]}`.
**Normalise:** `source_id = sha1(url)`, `title`, `body = description + "\n" + content` (content is truncated to 200 chars by the provider on free tier — acceptable), `outlet = source.name`, `published_at = publishedAt`.
**Limits:** 100 req/day on the developer tier. At 15-min cadence that is 96/day for a single page — keep `page ≤ 1` unless `NEWSAPI_TIER=paid`. Log `X-RateLimit` headers if present.
**If the repo already has a `news` schema fed by NewsAPI:** skip this feed and instead run `ingest/news_repo_reader.py` that selects rows from that schema matching the theatre `places`/`actors` aliases (ILIKE any) since `since`, normalising to `RawItem` with `source='newsapi'`. Decide at pre-flight; document in `ARCHITECTURE.md`.

## 3. WorldNews API — `ingest/news_worldnews.py`

**Request:** `GET https://api.worldnewsapi.com/search-news`
Headers: `x-api-key: $WORLDNEWS_KEY`
Params: `text` = same query string without boolean operators (provider does its own matching; pass `Kharg Hormuz Iran tanker Houthi Fujairah`), `earliest-publish-date` = `since` as `YYYY-MM-DD HH:MM:SS`, `language=en`, `sort=publish-time`, `sort-direction=DESC`, `number=100`, `offset=0`.
**Response:** `{news:[{id, title, text, url, publish_date, author, source_country, sentiment}], available}`.
**Normalise:** `source_id = str(id)`, `body = text[:4000]`, `outlet` = domain of `url`, keep `sentiment` in `raw`.

## 4. GDELT 2.0 — `ingest/news_gdelt.py`

1. `GET http://data.gdeltproject.org/gdeltv2/lastupdate.txt` → three lines `size hash url`; take the line whose url ends in `.export.CSV.zip`. Keep the last processed url in `feed_status` (store in `last_error_msg`? no — add a small `grp.kv` table `key text primary key, value text` in 28.02 if needed; simpler: derive from filename timestamp and compare with `last_success`).
2. GDELT publishes every 15 min; between runs there may be 1–2 new files. Reconstruct filenames `YYYYMMDDHHMMSS.export.CSV.zip` for each 15-min slot since `last_success` and fetch `http://data.gdeltproject.org/gdeltv2/<name>`; 404 → skip.
3. Unzip in memory, parse tab-separated, **no header**, 61 columns. Column indices (0-based): `0 GlobalEventID, 1 Day, 7 Actor1CountryCode, 6 Actor1Name, 17 Actor2CountryCode, 16 Actor2Name, 26 EventCode, 28 EventRootCode, 29 QuadClass, 30 GoldsteinScale, 31 NumMentions, 32 NumSources, 34 AvgTone, 52 ActionGeo_FullName, 56 ActionGeo_Lat, 57 ActionGeo_Long, 59 DATEADDED, 60 SOURCEURL`. Verify against the GDELT 2.0 codebook on first run and pin in a comment.
4. Filter: (`Actor1CountryCode` ∈ `country_codes` or `Actor2CountryCode` ∈ `country_codes`) and (`EventRootCode` ∈ `root_codes` or `GoldsteinScale ≤ goldstein_max`) and (`ActionGeo_Lat` within `10–42 N` and `ActionGeo_Long` within `30–65 E`, or lat/long empty).
5. **Normalise:** one `RawItem` per distinct `SOURCEURL` (collapse rows sharing a url; keep max severity hint = min GoldsteinScale). `source_id = GlobalEventID` of the first row, `title` = `f"{Actor1Name or Actor1CountryCode} → {Actor2Name or Actor2CountryCode}: CAMEO {EventCode} ({ActionGeo_FullName})"`, `body` = the same plus `Goldstein {g}, tone {t}, mentions {m}`, `url = SOURCEURL`, `published_at` = `DATEADDED` parsed `%Y%m%d%H%M%S` UTC. Keep the raw row in `raw`.
6. GDELT gives structure not prose; the classifier receives the synthetic title/body and treats `source_tier` as 3 unless the url domain is tier-1 (§7 domain list).

## 5. Manual / X paste — `ingest/news_manual.py`

Input model `ManualItem`: `text: str` (required, the post text or screenshot transcription), `author: str|None` (handle), `published_at: datetime|None` (default now), `url: str|None`, `outlet: str|None` (default `"X"`), `source: Literal['manual','x_paste']` (default `x_paste`), `quoted_text: str|None`, `media_note: str|None` (e.g. "SNN TV footage of tanker with tug alongside").

Normalise: `title = text[:140]`, `body = text + ("\n\nQUOTED: " + quoted_text) + ("\n\nMEDIA: " + media_note)`, `author`, `source_id` per §1.

Returns the event after classify; the API layer (28.09) wraps it.

## 6. Embeddings and dedup — `compute/embed.py`, `compute/dedup.py`

- Model `sentence-transformers/all-MiniLM-L6-v2` loaded once per process (CPU, ~90 MB, cache under `~/.cache` — add to Dockerfile layer). Input text = `title + " " + body[:400]`, normalised to unit length.
- `dedup(item) -> int | None`:
  1. Candidates = `repo.fetch_recent_embedded(hours=cfg.embeddings.dedup_window_hours)` (items with `event_id` set).
  2. Cosine: pgvector `order by embedding <=> :vec limit 1` if available; else Python dot product over candidates (bounded — 6 h of items, typically < 500).
  3. If max similarity ≥ 0.90 → `repo.attach_item_to_event(item.id, event_id, item.published_at)` → return `event_id`. `attach` sets `first_seen = least(first_seen, published_at)`, `last_seen = greatest(...)`, `item_count += 1`, `updated_at = now()`.
  4. Else → return `None` (candidate for classification).
- Additional hard-dedup before embedding: identical `url` (after stripping `utm_*`, `?s=`, trailing `/`) within 24 h → attach without embedding.
- Never merge across `theatre`.

## 7. Classification — `compute/classify.py`

### 7.1 Call

`POST https://api.anthropic.com/v1/messages`
Headers: `x-api-key: $ANTHROPIC_API_KEY`, `anthropic-version: 2023-06-01`, `content-type: application/json`.
Body:

```json
{"model": "claude-haiku-4-5-20251001", "max_tokens": 400, "temperature": 0,
 "system": "<contents of prompts/classify_system.md with theatre actors/places injected>",
 "messages": [{"role":"user","content":"SOURCE: newsapi | OUTLET: Reuters | PUBLISHED: 2026-09-05T11:56Z | URL: ...\nTITLE: ...\nBODY: ..."}]}
```

Parse `content[0].text` → strip code fences → `json.loads` → validate against `ClassifyOut`. On parse/validation failure retry once with the instruction "Return only the JSON object." appended; second failure → store `type='other'`, `confidence=0`, `summary=title[:200]`, flag `meta.classify_error`.

Record `usage.input_tokens/output_tokens` to `grp.llm_usage`. Before each call check `repo.llm_calls_today() < daily_call_cap`; if exceeded, leave items `classified=false` and log `llm_cap_reached` — the next run picks them up.

### 7.2 Output schema `ClassifyOut`

```json
{"actor":"US","target":"IRAN","theatre":"gulf",
 "type":"strike","severity":4,"source_tier":2,"confidence":0.86,
 "summary":"US reportedly struck an Iranian tanker near Kharg Island; footage via SNN TV, unconfirmed by CENTCOM.",
 "is_threat":false,"references_prior_threat":true,"threat_deadline":null,
 "off_theatre":false}
```

Constraints: `actor,target ∈ actors ∪ {OTHER}`; `type ∈` the events check list; `severity 1–5`; `source_tier 1–3`; `summary ≤ 200 chars`, one sentence, no hashtags; `off_theatre=true` → item stored, `classified=true`, **no event created**.

### 7.3 `prompts/classify_system.md` — required content

- Role: event coder for a geopolitical risk model covering the `{theatre_display_name}` theatre. Return one JSON object only.
- Actor mapping table injected from config aliases.
- **Type definitions:** `threat` — stated intent or ultimatum to use force/seize/sanction, including deadlines; `strike` — kinetic action against any target; `seizure` — boarding/detention of vessel or aircraft; `sanction` — new sanctions/designations/export controls; `talks` — negotiations, envoy meetings, ceasefire proposals; `walk_back` — retraction, deadline extension, "no plans to", ceasefire acceptance; `denial` — party denies an alleged action; `airspace`/`aircraft`/`vessel` — only when the item is itself about airspace closure / government aircraft movement / vessel behaviour (the feeds normally create these; news may too); `other` — everything else including market commentary.
- **Severity anchors:** 1 rhetoric/opinion; 2 posture, exercise, deployment announcement; 3 seizure, sanction package, FIR closure, credible threat with deadline ≤ 7 d; 4 kinetic strike on commercial/energy asset, tanker hit, port strike; 5 strike on state military asset with casualties, infrastructure destruction, strait closure declared.
- **Source tier:** 1 Reuters, Bloomberg, AP, AFP, WSJ, FT, official government/military channels (CENTCOM, IRNA/Tasnim as official Iranian, IDF); 2 major national outlets (NYT, BBC, Al Jazeera, Times of Israel, Haaretz), verified analysts, state TV with footage (SNN/Press TV), OSINT accounts with track record; 3 anonymous/unverified social, aggregators, GDELT synthetic rows.
- "Reportedly" / "unconfirmed" reduces `confidence`, not `severity`.
- Commentary *about* an event (e.g. a trader's post quoting a tanker-strike report) codes the underlying event with `source_tier` of the *quoted* source and `confidence` reduced by 0.1.
- Set `references_prior_threat=true` when the text ties the action to an earlier ultimatum (feeds taco pairing).

### 7.4 Judge pass

If `confidence < 0.55` or `severity ≥ 4 and source_tier == 3`: re-run once on `claude-sonnet-5` with `prompts/judge_system.md` (same schema, instruction to be conservative on severity for unverified sources). Judge output replaces the first. Still `< 0.55` → store as `type='other'` with `meta.needs_review=true`; these rows appear in the Grafana review table (28.10) for manual reclassification via `PATCH /grp/events/{id}` (28.09).

### 7.5 Event insert

`insert_event(theatre, first_seen=item.published_at, last_seen=item.published_at, actor, target, type, severity, source_tier, confidence, summary, item_count=1, meta={source_ids:[...], classify_model, judge_used})`, then `raw_items.event_id = id, classified = true`. Then call `taco.on_new_event(event)` (28.08 §2) and `alerts.engine.on_event(event)` (28.10 §5).

## 8. Job wiring — `jobs/job_news.py`

```
for feed in [NewsApiFeed, WorldNewsFeed, GdeltFeed]: feed.run()        # each guarded; one failing does not stop others
items = repo.fetch_unclassified(limit=200)
for item in items:
    if item.embedding is None: item.embedding = embed(item)
    eid = dedup(item)
    if eid is None: classify_and_insert(item) else: mark classified
composite hint: if any new event with severity ≥ 4 → run job_composite immediately (in-process call)
```

Log per run: `{"job":"news","fetched":{"newsapi":n,"worldnews":n,"gdelt":n},"new_events":k,"attached":m,"llm_calls":c}`.
