# Spec 28.01 — Configuration Files

All four files live in `grp/config/`. They are loaded once per process by `grp/config/__init__.py` → `load_config() -> GrpConfig` (Pydantic model, validated on load; a bad config fails fast). Nothing in the code may hard-code a value that belongs here.

`GrpConfig` fields: `theatre: TheatreConfig`, `model: ModelConfig`, `sources: dict[str, SourceConfig]`, `alerts: list[AlertRule]`. Env var `GRP_THEATRE` (default `gulf`) selects `theatre_<name>.yaml`.

## 4. `alerts.yaml`

```yaml
rules:
  - id: airspace_closure
    on: event
    when: "event.type == 'airspace' and event.severity >= 3"
    cooldown_min: 60
    channels: [log, email]
  - id: gov_aircraft_landing
    on: event
    when: "event.type == 'aircraft' and event.severity >= 3"
    cooldown_min: 120
    channels: [log, email]
  - id: vessel_anomaly_cluster
    on: event
    when: "event.type == 'vessel' and event.meta.get('cluster_count', 1) >= 3"
    cooldown_min: 180
    channels: [log, email]
  - id: severity_5
    on: event
    when: "event.severity == 5"
    cooldown_min: 30
    channels: [log, email, exhibit]
  - id: regime_change
    on: score
    when: "score.regime != prev.regime"
    cooldown_min: 0
    channels: [log, email, exhibit]
  - id: fade_trigger
    on: score
    when: "score.fade and not prev.fade"
    cooldown_min: 0
    channels: [log, email, exhibit]
  - id: feed_stale
    on: feed
    when: "feed.age_min > 2 * feed.cadence_min"
    cooldown_min: 240
    channels: [log]
```

Expressions are evaluated with a restricted evaluator (`simpleeval` or an AST whitelist) — never `eval`. Variables exposed: `event`, `score`, `prev`, `feed` as plain attribute objects.
