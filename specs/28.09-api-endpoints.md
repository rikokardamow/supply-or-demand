# Spec 28.09 — API Endpoints

Files: `api/routers/grp.py`, `api/models/grp.py`. Register in `api/main.py` with `app.include_router(grp_router, prefix="/grp", tags=["grp"])` following the existing pattern. Read-only against Postgres except two write endpoints guarded by `X-GRP-TOKEN`.

All GeoJSON is RFC 7946 (`[lon, lat]`), so the phase-two Leaflet frontend consumes it unchanged. All timestamps ISO-8601 UTC. Pagination: `limit` (default 50, max 500) + opaque `cursor` (base64 of `first_seen|id`).

---

## 1. Auth dependency

```python
def require_write_token(x_grp_token: str = Header(...)):
    if not hmac.compare_digest(x_grp_token, os.environ["GRP_WRITE_TOKEN"]): raise HTTPException(401)
```

## 2. Endpoints

### `GET /grp/latest?theatre=gulf`
```json
{"ts":"2026-09-05T14:30:00Z","theatre":"gulf","grp":19.8,"regime":"calm","fade":false,
 "model_version":"0.2.0","stale":[],
 "components":{"escalation":0.482,"escalation_mass":1.314,"dominant_actor":"US","taco_dominant":0.357,
               "airspace":0.535,"notam_term":0.8,"aircraft_term":0.45,"delay_term":0.0,
               "physical":0.228,"ais_term":0.30,"eia_term":0.20,"crowded":true},
 "positioning":{"d":"2026-09-05","wti_net_pct_2y":0.85,"brent_m1_m3":1.42,"crowded_reason":"..."},
 "top_events":[{"id":812,"first_seen":"...","actor":"US","type":"strike","severity":4,"summary":"...","url":"..."}]}
```
`top_events` = 5 highest-mass events in the last 48 h. 404 if no score yet.

### `GET /grp/history?theatre=gulf&from=&to=&step=30m`
`step ∈ {30m, 1h, 6h, 1d}` → time-bucketed (`date_bin`) rows: `[{ts, grp, regime, fade, escalation, taco_dominant, airspace, physical, crowded, stale}]`. Default range last 14 d.

### `GET /grp/events?theatre=&since=&until=&type=&actor=&min_severity=&needs_review=&limit=&cursor=`
Returns `{items:[EventOut], next_cursor}`. `EventOut` = `v_events_review` columns + `resolution`, `parent_threat_id`, `meta`.

### `GET /grp/events/{id}`
`EventOut` + `items:[{id, source, outlet, author, title, url, published_at}]` + `children:[EventOut]` (events whose `parent_threat_id` = id) + `parent: EventOut|null`.

### `POST /grp/events`  *(write token)*
Body = `ManualItem` (28.03 §5). Runs normalise → upsert → embed → dedup → classify **synchronously** (timeout 30 s). Response `201` with `{event: EventOut, attached_to_existing: bool, item_id}`. If `off_theatre` → `200 {event: null, item_id, reason: "off_theatre"}`.

### `PATCH /grp/events/{id}`  *(write token)*
Body: any of `{actor, target, type, severity, source_tier, summary, needs_review:false}`. Updates the row, sets `meta.manual_override = {fields, at}`, re-runs `taco.on_new_event` if `type` changed, and triggers `job_composite` in-process. Used from the Grafana review table link.

### `GET /grp/taco?theatre=gulf&days=90`
`[{d, actor, threats, follow_throughs, walk_backs, unresolved, credibility}]`.

### `GET /grp/positioning?days=60`
Rows of `grp.positioning`.

### `GET /grp/physical?weeks=26`
Rows of `grp.physical_weekly`.

### `GET /grp/ais/daily?geofence=&days=30`
Rows of `grp.ais_daily`.

### `GET /grp/notams/geojson?active=true&min_severity=2`
FeatureCollection; geometry = `geom` as GeoJSON if PostGIS else the `bbox` as a Polygon ring; properties `{id, number, fir, severity, keywords, effective_from, effective_to, text}`.

### `GET /grp/vessels/geojson?geofence=&hours=6&anomalies_only=false`
FeatureCollection of Points from `v_vessels_latest`; properties `{mmsi, name, ship_type, sog_kn, cog_deg, destination, draught_m, geofence, ts, anomalies:[kind...] (last 24 h)}`.

### `GET /grp/vessels/{mmsi}/track?hours=48`
Feature LineString of positions + `properties.positions:[{ts, sog, cog, geofence}]`.

### `GET /grp/aircraft/geojson?hours=24`
FeatureCollection: one LineString per `icao24` (ordered positions) with `{icao24, callsign, type_code, operator, last_geofence, last_ts}`; plus Point features for landings in the window with `{event_id, geofence, ts}`.

### `GET /grp/geofences/geojson`
The theatre geofence polygons and airport circles (as 32-point polygons) from config — lets the map draw the boxes.

### `GET /grp/feeds`
Rows of `v_feed_health` + `llm_calls_today`, `llm_cap`.

### `GET /grp/exhibits?limit=20`
Rows of `grp.exhibits` with a `url` built from `GRP_EXHIBIT_BASE_URL` if set (static file mount) else the path.

### `POST /grp/run/{job}`  *(write token, local/dev only — disabled unless `GRP_ALLOW_RUN=1`)*
`job ∈ {news, notam, aircraft, delays, physical, positioning, composite, exhibits}` → runs the job in-process, returns its log dict. Used by the Makefile and for manual verification.

## 3. Pydantic models (`api/models/grp.py`)

`ScoreOut, ComponentsOut, PositioningOut, EventOut, EventDetailOut, ManualItem, EventPatch, TacoRow, PhysicalRow, AisDailyRow, FeedHealthRow, ExhibitRow, GeoJSONFeatureCollection` (typed `Feature[Point|LineString|Polygon]`). Use `model_config = ConfigDict(from_attributes=True)`.

---

## 4. Errors and CORS

- 401 bad token; 404 unknown event/no score; 422 validation; 503 `{"detail":"classifier unavailable"}` if the LLM call fails on `POST /grp/events` (item is still stored, `classified=false`, will be picked up by the next `job_news` run — say so in the response).
- CORS per the API service's existing config (future frontend origin).
